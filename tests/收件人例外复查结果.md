# 指定收件人保留姓名的复查

“设备培训”要求只隐藏人名，保留收件人梁蕊的姓名。对照版本 `338f66b` 把整条写作提示词替换成了一个敏感内容代号。本轮使用相同的本地 Aztec-Coder-4B Q4_K_M 权重，修改了员工要求的解析和逐处替换逻辑。自动初稿如下。

```text
【写作要求】
给梁蕊写邮件，问她是否收到【人员B】的讲义。

【项目材料】
【人员B】负责演示，梁蕊负责收集问题。
```

## 80 份已有材料

## 收件人专项

8 个真实推理用例全部通过，含原失败稿、交换保留对象、姓名只在提示词出现、保留人未出现、只有保留人、同姓重复出现、分两条指定两名收件人、遮全部人名的对照。断言比较完整对外稿、代号一致性、复制复查和按映射回填后的原文，也检查了单独改选提示词中一处收件人后的结果。复制和回填测试调用工作台实际使用的函数。

复测入口为 `tests/recipient-review.cjs`，全量评分入口为 `tests/evaluate.cjs all result.json`。两个脚本均用项目附带的 Node 运行。

## 剩余问题

“玻璃杯供货”仍多遮正常运输的“三天”，“空调维保”仍漏遮正文中比约定晚的“两天”。“展板清点”和“司机交接”的其他人名指令写法仍可能使一整句提示词被替换。下一轮可优先用相同天数、不同用途的配对稿检查延期判断，分别统计正文和提示词的错误。
