# 墨隐 Windows 桌面版

把整个 ZIP 解压到可写目录，将已校验的权重放入 `models`，双击 **墨隐.exe**。重复打开会回到已有工作台。Windows 需要 x64 WebView2 Runtime 和 .NET Framework 4.6.2 或更高版本。如提示缺少 WebView2，可使用微软提供的 Evergreen x64 离线安装程序。[微软运行时下载](https://developer.microsoft.com/microsoft-edge/webview2/)

工作台就绪后可导入 Word、填写本地脱敏要求并选择快速或高精度模式。复制对外稿后请保留工作台窗口，直到完成回填。「文件涂黑」在独立窗口打开，导出时选择保存位置。退出主窗口会关闭本次启动的本地服务。权重校验、内网模式和读写范围见同目录 README.md。
